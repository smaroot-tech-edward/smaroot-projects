## What is public here

- Business problems, workflow descriptions, public engineering facts and the authorized presentation images.
- The community interfaces are anonymized reconstructions based on actual project UI. Battery service interfaces use anonymized identity/business data.
- Suggestions headed “acceptance questions for a similar project” describe a possible new engagement; they are not undisclosed acceptance results from the original customer.
- Project start dates, contracting entities and business-performance metrics are not inferred from an interface or from a repository's creation date.

## What remains in the appropriate private evidence store

Customer contracts, acceptance documents, original personal records, private conversations, production credentials and non-public source code are not included in this repository. Public case classifications and evidence summaries support the scope described on each page.

Images are drawn from the public sources above and retain their original files. This repository does not grant an additional open-source or asset license.
